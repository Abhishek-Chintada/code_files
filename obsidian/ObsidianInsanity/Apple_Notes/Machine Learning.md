- [ ] Machine learning is the key to most of the automated tasks these days like self driving cars, computer playing games etc. The ML engineers are designated to provide the system with large data sets through which the machine analyses the best patterns for achieving excellence in its domain.
- [ ] As of now, I understood that the machine learning involves a lot of math, I mean a lot, including functional analysis, matrices and vectors, sets and classes, statical analysis, and a major part of probability also.
- [ ] An algorithm is a sequence of instructions the should be carried out to transform the input to the output.
- [ ] There are many problems which have no specific algorithmic approach but are effortlessly done by a human being without ever noticing, like recognising a person by his photograph, walking in a room without hitting any objects etc.
- [ ] There always lies certain patterns in data which are used by the machine to produce good and useful approximations. (Pattern Recognition)
- [ ] Application of machine learning methods to large data sets is called data mining.
- [ ] In ML we have a model which has a set of parameters, and learning is the execution of a computer program to optimise the parameters in model using the training data or past experience. The model may be predictive or descriptive or both.
- [ ] We have two big problems to take care of while solving the ML problems, firstly the optimisation problem for the algorithms and secondly the predictive accuracy.
- [ ] Association Rules - Supermarket-chain | basket analysis | association rule | conditional probability - the condition is the guaranteed purchase (we may have more than one condition)
- [ ] Classification - bank loans | associating risks with customers available attributes | providing credit scoring | classifying as high risk or low risk customer. (Discriminant - the function which separates the examples of different classes.) | we may also go on to make a prediction about to what extent the loan will be repaid by the specific customer.
- [ ] Pattern recognition | optical character recognition | face recognition | medical diagnosis | speech recognition .
- [ ] Natural language processing | Spam filtering | Summarising | trending sort | sentiment prediction | machine translation (language translation). | biometrics
- [ ] A rule - simple model that explains the data and the process underlying the data - learning a rule from the data is called knowledge extraction.
- [ ] Compression - by fitting a rule for the data we may get a simpler explanation which helps in optimisation i.e for example if we know the rule of addition we need not remember the sum of every possible pair of numbers.
- [ ] Outlier detection -> novelty detection. (Basically fraud detection).
