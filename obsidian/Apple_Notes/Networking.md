## The OSI Model :

The osi model means the open systems interconnection reference model. It’s a guideline and a broadway to define how data moves across the network. This is just like a sign convention to make the developers from around the world communicate with each other in ease. The osi protocol suite did not catch on but the model is still used to this day.
